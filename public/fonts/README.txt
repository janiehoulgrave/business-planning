Put the Compass Sans web font files in this folder with these exact names:

  CompassSans-Regular.woff2
  CompassSans-Medium.woff2
  CompassSans-Bold.woff2

If you only have .otf or .ttf files, convert them to .woff2 first (or ask Claude to).
Until the files are here, the app falls back to Helvetica/Arial automatically.
